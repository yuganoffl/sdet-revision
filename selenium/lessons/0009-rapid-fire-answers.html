01How do you handle a dropdown?

Wrap the element in the Select class, then choose by visible text, value or index.

It only works on a real <select> tag. If the dropdown is built from divs, you just click the toggle and then the option.

Select country = new Select(driver.findElement(By.id("country")));

country.selectByVisibleText("India");
country.selectByValue("in");
country.selectByIndex(1);

country.getFirstSelectedOption().getText();

02How do you handle multiple windows?

Get the handles, copy them into a List, then switch by index.

getWindowHandles() returns a Set, which has no get(i). The ArrayList is what makes a window addressable by position.

Set<String> windows = driver.getWindowHandles();

List<String> windowList = new ArrayList<>(windows);

driver.switchTo().window(windowList.get(1));

Index 0 is the original, so windowList.get(0) takes you back. close() shuts the current window, quit() ends the session.

03Write code to capture a screenshot.

Cast the driver to TakesScreenshot, call getScreenshotAs, then copy the file where you want it.

OutputType.FILE gives you a temp file that is deleted when the JVM exits, so the copy is what actually saves it.

TakesScreenshot ts = (TakesScreenshot) driver;

File source = ts.getScreenshotAs(OutputType.FILE);

File destination = new File("./screenshots/homepage.png");

FileUtils.copyFile(source, destination);

FileUtils is org.apache.commons.io.FileUtils, and it creates the folder for you.

04How do you handle alerts?

driver.switchTo().alert(), then accept, dismiss or type into it.

An alert is the browser's own dialog, not part of the page, so no locator reaches it.

Alert alert = driver.switchTo().alert();

alert.getText();
alert.accept();            // OK
alert.dismiss();           // Cancel
alert.sendKeys("Yugan");   // prompt only

Leave one open and every command after it throws UnhandledAlertException.

05How do you perform drag and drop?

Actions.dragAndDrop(source, target), followed by perform().

Nothing in an Actions chain runs until perform() is called.

Actions actions = new Actions(driver);

actions.dragAndDrop(source, target).perform();

If it silently does nothing, the page is using HTML5 drag events. Then use clickAndHold(source).moveToElement(target).release().perform().

06Write code to handle frames.

driver.switchTo().frame(...) by name, id, index or WebElement.

Elements inside an iframe are invisible to the driver until you switch in, so you get NoSuchElementException and it looks like a broken locator.

driver.switchTo().frame("theFrame");

driver.findElement(By.id("inside")).sendKeys("hello");

driver.switchTo().defaultContent();

Forgetting defaultContent() is the common bug, and the failure then appears somewhere unrelated to the frame.

07How do you handle cookies?

Everything is on driver.manage(): get, add, delete.

The real use is skipping login. Save the session cookie once, then inject it so later tests start already authenticated.

Set<Cookie> all = driver.manage().getCookies();
Cookie session   = driver.manage().getCookieNamed("JSESSIONID");

driver.manage().addCookie(new Cookie("theme", "dark"));
driver.manage().deleteCookieNamed("theme");
driver.manage().deleteAllCookies();

You must already be on the cookie’s domain before addCookie works.

08How do you handle exceptions in Selenium?

In a test, you mostly do not. You assert the failure instead of catching it.

A catch block turns a real application failure into a green pass. Catching belongs in the framework, in teardown and in listeners.

@Test(expectedExceptions = NoSuchElementException.class)
public void findElementThrowsWhenNothingMatches() {
    driver.findElement(By.id("nope"));
}

The five to know: NoSuchElement, Timeout, StaleElementReference, ElementNotInteractable, ElementClickIntercepted. All are unchecked.

09How do you verify an element is displayed?

isDisplayed() returns true when the element is visible to a user.

It throws NoSuchElementException if the element is missing, so use findElements(...).isEmpty() when it might not exist at all.

boolean shown = driver.findElement(By.id("banner")).isDisplayed();

element.isEnabled();     // not disabled
element.isSelected();    // checkbox, radio or option is chosen

10How do you execute JavaScript?

Cast the driver to JavascriptExecutor and call executeScript.

Elements you pass in arrive as arguments[0]. To get a value back, the script must say return.

JavascriptExecutor js = (JavascriptExecutor) driver;

js.executeScript("arguments[0].scrollIntoView(true);", element);

String title = (String) js.executeScript("return document.title;");

Fine for scrolling. A JS click to get past a failing normal click usually hides a real bug.

11How do you check for broken links on a page?

Collect every href, send an HTTP request to each, and check the response code. 400 or above is broken.

Selenium cannot do this alone. It finds the links and HttpURLConnection checks them.

List<WebElement> links = driver.findElements(By.tagName("a"));

for (WebElement link : links) {
    String url = link.getAttribute("href");
    if (url == null || url.isEmpty()) continue;

    HttpURLConnection conn = (HttpURLConnection) new URL(url).openConnection();
    conn.setRequestMethod("HEAD");
    conn.connect();

    if (conn.getResponseCode() >= 400) {
        System.out.println("BROKEN  " + conn.getResponseCode() + "  " + url);
    }
}

Use HEAD rather than GET, because you only need the status and not the body.

12How do you wait for an element to be visible?

WebDriverWait with ExpectedConditions.visibilityOfElementLocated.

Prefer visibility over presence. Presence is satisfied by a hidden element, so getText() comes back empty.

WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));

WebElement el = wait.until(
        ExpectedConditions.visibilityOfElementLocated(By.id("results")));

Never mix this with an implicit wait. Each poll then blocks for the implicit duration, so the real timeout is longer than you asked for.

13How do you perform a mouse hover?

Actions.moveToElement(element), followed by perform().

WebElement has no hover method, so Actions is the only way.

Actions actions = new Actions(driver);

actions.moveToElement(driver.findElement(By.id("menu"))).perform();

14How do you handle a file upload?

sendKeys() the absolute file path onto the <input type="file">.

Do not click it. Clicking opens the operating system dialog, which Selenium cannot drive at all.

WebElement upload = driver.findElement(By.cssSelector("input[type='file']"));

upload.sendKeys("/Users/yugan/Documents/invoice.pdf");

The path must be absolute. If there is no file input and only an OS dialog, Selenium cannot help and you need AutoIT or Robot.

15How do you scroll to the bottom of the page?

Execute window.scrollTo(0, document.body.scrollHeight).

There is no Selenium command to scroll the window itself. Scrolling is JavaScript.

JavascriptExecutor js = (JavascriptExecutor) driver;

js.executeScript("window.scrollTo(0, document.body.scrollHeight);");

window.scrollTo(0, 0) goes back to the top, and scrollIntoView goes to one element.

16How do you handle a right click?

Actions.contextClick(element), followed by perform().

That opens the application's own context menu, which you then locate normally. It cannot drive the browser's native menu.

Actions actions = new Actions(driver);

actions.contextClick(driver.findElement(By.id("row-3"))).perform();

Double click is the same shape: doubleClick(element).

17How do you capture and print all links on a page?

findElements(By.tagName("a")), then loop and read the text and the href.

findElements returns an empty list rather than throwing, so a page with no links is not an error.

List<WebElement> links = driver.findElements(By.tagName("a"));

System.out.println("Total links: " + links.size());

for (WebElement link : links) {
    System.out.println(link.getText() + "  ->  " + link.getAttribute("href"));
}

This counts hidden links too. Filter on isDisplayed() if the question is what a user can see.

Twelve things to say only if asked

These are the follow-ups that hang off the seventeen above. One line each is enough.

Dropdown is not a <select>Click the toggle, wait for the options, click one.
Window handleAn opaque id string. Not a title, not a URL.
close() vs quit()close() shuts one window. quit() ends the session and kills the driver process.
Screenshot scopeThe viewport, not the full scrollable page. Full-page is not in the W3C standard.
Alert vs modalA native alert needs switchTo(). An HTML modal is a normal element.
Drag and drop fails silentlyProbably HTML5 drag events. Use clickAndHold, moveToElement, release.
Nested framesparentFrame() goes up one. defaultContent() goes all the way out.
Cookie for loginMust be on the domain before addCookie, then refresh.
Why not catch in a testIt turns a real failure into a green pass.
JS clickBypasses what a user could do, so it hides the bug rather than fixing it.
Broken linksSelenium finds them, HttpURLConnection checks them. Use HEAD.
File upload with no inputSelenium cannot drive an OS dialog. AutoIT or Robot.
